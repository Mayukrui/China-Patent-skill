# China-Patent-skill

从热门项目凝练 skill，优化专利材料的叙述内容。

本仓库参考 [PatentClaw](https://github.com/lzlfwow/PatentClaw) 的证据链、检查表和逐问题修订思路，形成面向中文专利申请草稿的可复用技能。以原理、必要技术关系和真实效果为中心，避免把一次训练的配置或论文消融表直接搬入介绍文件。

## 默认交付

生成前先询问文件数量，推荐四份：权利要求书、说明书、说明书附图、说明书摘要。用户可指定合并或只生成部分文件。交底书、证据与审查记录作为本地工作材料。

## 主要规则

- 介绍文件不写具体训练超参数；保留必要技术原理、公式关系和输入输出。
- 默认不放论文消融数据；确需数据支撑时采用最少且可追溯的真实结果。
- 流程图优先用本机Visio、draw.io等专业软件，找不到时从官方渠道获取合适本地工具；保留可编辑源文件。
- 说明书附图包含真实项目效果，来源不明时先询问用户，不伪造、不用其他版本冒充目标方案。
- 真实对照、良好个例和总体性能分别解释；需要三维导出或拼接时核验坐标和覆盖范围。
- 保密材料默认本地处理，禁止上传论文、结果及其派生内容。

## 使用

将本仓库的 `patentclaw-local` 文件夹复制到所用Agent的技能目录，或用支持仓库路径的skill安装器安装该文件夹。在会话中调用：

```text
使用 $patentclaw-local 将本地技术材料整理为中文专利草稿。
```

先按照 [SKILL.md](patentclaw-local/SKILL.md) 确认交付范围和实际执行边界。严格零外传时，材料须由人工或经过核验的本地模型处理；本地保存不等于本地推理。上游在线模式需要模型服务，但本技能默认不用这些在线入口，也不需要填写模型Key。

本仓库仅含通用技能、公开来源说明和合成测试；不提供实际论文、专利稿、病例、实验结果、模型、账号、凭据或本机配置。用户生成的材料不应写入本仓库。

## 验证

```text
python -B -m unittest discover -s patentclaw-local/scripts -p "test_*.py" -v
```

`local_guard.py`只检查本地源包与合同结构，不提供推理、不更改防火墙、不保证法律充分性。技能本身不替代专利专业审查；省略具体训练参数不构成侵权判断保证。上游原生交付是技术交底书，四份完整申请稿属于本技能的扩展。
