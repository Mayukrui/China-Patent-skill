# 验证方法与限制

用Python标准库在临时目录运行合成测试，不安装新依赖，不使用实际论文、凭据、模型、网络或GPU。

    python -B -m unittest discover -s <skill目录>/scripts -p "test_*.py" -v

用skill-creator提供的quick_validate检查技能元数据；中文环境可加Python的-X utf8选项。它不验证写作质量或法律充分性。

结构测试检查隐私门槛、源文件范围、链接/越界引用、ZIP限额、危险TeX、证据引用、冻结hash、完整检查表、未审语义与伪造ready等拒绝路径。所有样例是临时合成材料，不把合成通过称为实际专利或科学效果验证。

行为审阅至少覆盖：文件数量未指定时先询问并推荐四份；明确数量不重复问；不在介绍中固化训练超参数；默认不搬用消融数据；专业软件原生图可编辑；缺真实效果来源时询问并保留待补；优选或历史版本不冒充总体或目标方法；缺空间元数据不硬拼接。

本技能和脚本不证明OS隔离、推理位置、遥测、同步、供应链、任意TeX安全或法律充分性。不能把结构检查当事实蕴含，也不能通过省略参数保证侵权结论。
